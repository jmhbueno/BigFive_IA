Análise das classificações dos itens pelo prompt do Gemini

Instruções dadas ao Gemini: Você fará o papel de um juiz especialista em teorias da personalidade, especialmente no que se refere ao modelo dos cinco grandes fatores, que é uma das teorias do traço. Considere que os cinco grandes fatores são: extroversão, amabilidade, conscienciosidade, neuroticismo e abertura. Esses traços são subdivididos em três facetas cada um:

  • Extroversão: sociabilidade, assertividade e nível de energia

  • Amabilidade: compaixão, respeito e confiança

  • Conscienciosidade: organização, produtividade e responsabilidade

  • Neuroticismo: ansiedade, depressão e labilidade emocional

  • Abertura: curiosidade intelectual, sensibilidade estética e imaginação criativa

Faça duas classificações para cada item: em um dos cinco fatores e em uma das três facetas do fator classificado. Apresente os resultados em uma tabela com três colunas: itens, classificação dos fatores, classificação das facetas.

Embeddings - Função

OBS: Você precisará criar uma API_KEY no Gemini e colá-la no campo api_key_gemini <- ["COLE SUA GEMINI_API_KEY AQUI"] do chunk abaixo.

# Pacotes -----------------------------------------------------------------

library(httr)
library(jsonlite)

# API Keys ----------------------------------------------------------------

# Sua chave de API do Gemini
api_key_gemini <- ["COLE SUA GEMINI_API_KEY AQUI"]


# Funções -----------------------------------------------------------------

#' Função para capturar embeddings da Gemini
#' Aceita só textos individuais
#' @param api_key É a chave da API
#' @param texto É um texto para ser transformado em embeddings
#' @param model é o modelo que será utilizado (recomenda-se `models/text-embedding-004` em 2024)
get_embeddings_gemini <- function(api_key, text, model) {
    require('httr','jsonlite')
    url <- paste0("https://generativelanguage.googleapis.com/v1beta/models/text-embedding-004:embedContent?key=", api_key)
    
    # Configura o cabeçalho da solicitação
    headers <- httr::add_headers(
        `Content-Type` = "application/json"
    )
    
   body <- list(
        model = model,
        content = list(
            parts = list(
                list(text = text)
            )
        )
    )
    
    # Faz a solicitação POST
    response <- httr::POST(url, headers, body = jsonlite::toJSON(body, auto_unbox = TRUE))
    
    # Verifica se a solicitação foi bem-sucedida
    if (response$status_code != 200) {
        stop("Erro na solicitação: ", response$status_code, "\n", httr::content(response, "text"))
    }
    
    # Parseia a resposta JSON
    response_content <- httr::content(response, "parsed", simplifyVector = TRUE)
    
    # Retorna os embeddings
    return(response_content$embedding$values)
}
